# shogiXbook

盤面が動く「読める・書ける・検証できる」将棋の本を作るためのツール。

紙の棋書にある構造的な不便さ — 盤面が動かない、図番号を追ううちに現在局面を見失う、変化手順が線形に潰されている、著者の推奨手を検証できない — を解消することを目的とする。

## いまできること

図面が本文の流れの中に組まれた、棋書に近い読み物として読める。図はその場で手順を進められる。PC とスマホで同じ画面が使える。

**「紙面の構造」を決めるための見比べ用プロトタイプの段階。** 「棋書らしさ」は言葉で詰めにくいので、画面右上の「見比べ」から次を切り替えて実物で比較できるようにしてある。

| 切り替え | 選択肢 |
| --- | --- |
| 紙面の構造 | ページめくり（リフロー） / 章＝ページ / スクロール / 連動（初版） |
| 図面の振る舞い | ①その場で進む ②静止図＋タップで拡大 ③主図ひとつ |
| 組方向 | 横書き / 縦書き |
| 分岐ツリー | 縦に伸ばす / 横に伸ばす |

**保存機能はまだない**（リロードすると編集内容は消える）。

```sh
npm install
npm run dev
```

## 方針

- Web アプリ（PWA）。PC・スマホ同一のアプリで、どちらでも読み書きできる
- サーバ・DB・アカウントなし。GitHub Pages に置き、データは各自のブラウザ内に保存する
- 将棋 AI はブラウザ内で動く WASM エンジンを既定とし、ネイティブエンジン連携は第二版

## 技術

TypeScript / React / Vite。

- 盤面の描画・操作・局面編集は [shogi-player](https://github.com/akicho8/shogi-player)（akicho8 氏）
- 将棋のルール・棋譜フォーマット（KIF・KI2・CSA・JKF・SFEN）・分岐の管理は [tsshogi](https://github.com/sunfish-shogi/tsshogi)
