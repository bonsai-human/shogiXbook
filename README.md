# shogiXbook

盤面が動く「読める・書ける・検証できる」将棋の本を作るためのツール。

紙の棋書にある構造的な不便さ — 盤面が動かない、図番号を追ううちに現在局面を見失う、変化手順が線形に潰されている、著者の推奨手を検証できない — を解消することを目的とする。

## 現在のステータス

## 想定する形

- Webアプリ（PWA）。PC・スマホ同一のアプリで、どちらでも読み書きできる
- サーバ・DB・アカウントなし。データは各自のブラウザ内に保存
- 将棋AIはブラウザ内で動くWASMエンジンを既定とし、本格的なネイティブエンジン連携は第二版で対応
