# shogiXbook

盤面が動く「読める・書ける・検証できる」将棋の本を作るためのツール。

紙の棋書にある構造的な不便さ — 盤面が動かない、図番号を追ううちに現在局面を見失う、変化手順が線形に潰されている、著者の推奨手を検証できない — を解消することを目的とする。

## いまできること

本文をスクロールすると、その箇所の局面に盤面が自動で追従する。盤面で駒を動かせば、その手が手順の木に追加され、既存の手と違えば新しい分岐になる。PC とスマホで同じ画面が使える。

**フェーズ P0（検証プロトタイプ）の段階。** 本文↔盤面の連動と、スマホでの盤面タッチ編集という「作ってみないと分からない」2 点を先に作って手触りを確かめるのが目的なので、**保存機能はまだない**（リロードすると編集内容は消える）。

```sh
npm install
npm run dev
```

## 方針

- Web アプリ（PWA）。PC・スマホ同一のアプリで、どちらでも読み書きできる
- サーバ・DB・アカウントなし。GitHub Pages に置き、データは各自のブラウザ内に保存する
- 将棋 AI はブラウザ内で動く WASM エンジンを既定とし、ネイティブエンジン連携は第二版

## 技術

TypeScript / React / Vite。将棋のルール・棋譜フォーマット（KIF・KI2・CSA・JKF・SFEN）は [tsshogi](https://github.com/sunfish-shogi/tsshogi) に委譲している。
